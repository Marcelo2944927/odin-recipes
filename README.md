# odin-recipes
A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum, featuring three classic Brazilian dishes: Prato Feito, Comida Baiana, and Feijoada.

## Skills Practiced
- Basic HTML boilerplate and semantic structure
- Headings, paragraphs, ordered and unordered lists
- Relative paths for local images and internal links
- Version control workflow with Git and GitHub
